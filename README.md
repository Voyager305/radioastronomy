# Relay — гайд по радиоастрономии для новичка

Практический путь от нуля до первой линии водорода (21 см) на бюджетном SDR.

Этот репозиторий — не вузовский курс, а **пошаговый гайд для полного новичка**: что купить, как собрать, что наблюдать первым, как понять результат. Физику объясняем с нуля, без школьного багажа.

## С чего начать

1. Прочитай [введение](guide/01-introduction.md) — зачем это и чего ждать.
2. Если физика/астрономия чужие — медленно пройди [физику для чайника](guide/02-physics-basics.md).
3. Возьми [минимальный набор](guide/03-equipment.md) и поставь Linux-[ПО](guide/04-software.md) на ThinkPad/нетбук.
4. Сделай [первые наблюдения](guide/05-first-observations.md), затем [линию водорода](guide/06-hydrogen-line.md).

## Карта пути

```text
Купить RTL-SDR + антенну
        ↓
Увидеть спектр (FM / ADS-B)
        ↓
Поймать Солнце
        ↓
Собрать HI-антенну + LNA
        ↓
Записать линию 1420.4 МГц
        ↓
Усреднить спектр и увидеть Млечный Путь
```

## Как пользоваться гайдом

- Иди **по порядку**, если ты совсем новичок.
- Глава 02 специально для тех, кто не знает физику и астрофизику — не пропускай её.
- Если железо уже есть — начни с [ПО](guide/04-software.md) и [первых наблюдений](guide/05-first-observations.md).
- Непонятный термин — сразу в [глоссарий](guide/glossary.md): там определения по разделам (небо, волны, водород, шум, антенны, SDR).

## Лицензия материалов

Текст гайда можно свободно копировать и адаптировать для личного обучения.
