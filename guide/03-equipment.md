## Принцип покупки

Покупай по уровням. Не собирай «обсерваторию» до первой успешной записи спектра.

```text
Уровень 0: убедиться, что SDR работает
Уровень 1: Солнце и грубые эксперименты
Уровень 2: линия водорода
Уровень 3: стабильность, карта, автоматизация
```

## Уровень 0 — минимальный набор

Хватает, чтобы войти в тему за один вечер.

| Компонент | Рекомендация | Зачем |
|-----------|--------------|--------|
| SDR | **RTL-SDR Blog V3** (или сопоставимый RTL2832U + R820T2) | Приёмник |
| Антенна | Телескопический диполь из комплекта / простая FM-антенна | Проверка |
| ПК | Небольшой Linux-ноут (ThinkPad / нетбук) | ПО, запись, поле |
| Кабель | Короткий USB 2.0 качественный | Питание + данные |

**Ориентир бюджета:** $30–50.

На этом уровне цель — FM, ADS-B, водопад, понимание интерфейса. Не HI.

### На что смотреть при покупке RTL-SDR

- Чипсет **R820T2** (или заявленный эквивалент в нормальных клонах).
- Разъём **SMA** предпочтительнее MCX для частых переподключений.
- Желателен TCXO (стабильнее частота) — у Blog V3 есть.
- Покупай у проверенного продавца: много плохих безымянных стиков.

## Уровень 1 — Солнце и более чистый приём

| Компонент | Зачем |
|-----------|--------|
| Внешняя антенна повыше / дальше от роутера | Меньше бытовых помех |
| Простой металлический экран / заземление по возможности | Меньше наводок |
| Питание ноутбука от батареи на тесте | Отсечь шум БП |

Солнце ловится даже на скромной антенне, если помех не катастрофа.

## Уровень 2 — линия водорода (главный набор новичка)

Это «нормальный старт» для настоящей радиоастрономии дома.

| Компонент | Рекомендация новичку | Комментарий |
|-----------|----------------------|-------------|
| SDR | RTL-SDR Blog V3 | Уже есть с уровня 0 |
| LNA | Малошумящий усилитель под **1420 МГц** (NF как можно ниже) | Ставить **у антенны** |
| Антенна HI | Яги / helical / небольшая тарелка / dual-dipole под 21 см | Важнее «правильная частота», чем красота |
| Кабель | Короткие низкопотерьные куски (RG316 / LMR-240 и аналоги) | Длинный тонкий кабель до LNA убивает чувствительность |
| Bias-T | Если LNA питается по коаксиалу | У Blog V3 bias-t есть |
| Фильтр | Band-pass около 1420 МГц (по возможности) | Режет сильный out-of-band мусор |

**Ориентир бюджета:** $80–150 суммарно, если HI-антенну сделать самому.

### Антенна: купить или сделать?

**Сделать самому** часто лучший путь новичка:

- диполь / сдвоенный диполь под 21 см;
- простая Яги из чертежа;
- coffee-can / horn-подобные конструкции — как учебный проект.

**Купить** имеет смысл, если не хочешь возиться с металлом и КСВ.

Правило:

> LNA рядом с антенной важнее, чем «идеальный» кабель от антенны до комнаты без LNA.

### Питание LNA

Варианты:

1. Bias-T через коаксиал (удобно).
2. Отдельное чистое питание у антенны (иногда тише).

Грязный импульсный БП рядом с LNA = самострел по чувствительности.

## Уровень 3 — комфорт и повторяемость

Докупай только когда уровень 2 уже дал HI-профиль хотя бы грубо.

| Апгрейд | Зачем |
|---------|--------|
| Лучшая направленная антенна / тарелка 0.6–1.2 м | Узкий луч, выше SNR |
| Фильтр SAW / cavity под HI | Чище спектр в городе |
| Корпус, герметизация, мачта | Улица и долгие сессии |
| Поворотная монтировка / разметка азимута | Карты по небу |
| Внешний термостабильный генератор / лучший SDR | Стабильность частоты |
| Raspberry Pi / мини-ПК у антенны | Автозапись |

Более дорогие SDR (Airspy, HackRF как TX/RX-платформа, SDRPlay и т.п.) полезны, но **не обязательны** для первой HI-линии.

## Чего не покупать на старте

- Огромную тарелку «на вырост» без места и монтировки.
- Криогенные мечты и professional feed за тысячи долларов.
- Десять разных антенн до первой успешной записи.
- Случайные усилители «широкополосный 0–6 ГГц мощный» — часто шумные и перегружают SDR.

## Типовые связки

### Связка A — квартира/балкон

```text
HI-диполь или компактная Яги
   → короткий кабель
   → LNA (+фильтр)
   → коаксиал в комнату
   → RTL-SDR
   → Linux-ноут (ThinkPad)
```

Ожидание: HI возможен, но RFI будет главным врагом.

### Связка B — дача/крыша/поле

```text
Яги или небольшая тарелка на мачте
   → LNA у облучателя
   → кабель вниз
   → SDR
```

Ожидание: заметно проще получить чистый профиль.

### Связка C — только учёба железа (без HI)

```text
Комплектный диполь → RTL-SDR → SDR#
```

Ожидание: FM/ADS-B/водопад за 30 минут.

## Чеклист перед заказом

- [ ] Есть понятное место для антенны (окно/балкон/крыша/двор)
- [ ] Понимаешь, чем питаешь LNA
- [ ] Кабель от антенны до LNA короткий
- [ ] Есть запас переходников SMA
- [ ] Не покупаешь всё сразу «на идеал»
