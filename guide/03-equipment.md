# 03. Оборудование: с чего начать

← [Основы физики](02-physics-basics.md) · [Оглавление](../README.md) · Далее: [Программное обеспечение →](04-software.md)

---

Глава отвечает на один вопрос: **что приобрести сразу, чтобы начать**. Детальный выбор антенн под линию водорода и особенности закупок в РФ вынесены в отдельные справочники (ссылки в конце главы) — к ним обращаются позднее, на уровне 2.

Базовый сценарий руководства: **RTL-SDR + Linux на ноутбуке**, затем антенна под линию водорода 21 см.

> **Не обязательно понимать всё оборудование сразу.** Для первого включения достаточно приёмника, ноутбука и комплектной антенны (уровень 0 ниже). Антенна под HI, МШУ и фильтры понадобятся только на уровне 2.

## Ключевые сокращения

Восемь терминов, которые встретятся в этой главе постоянно. Полный список — в [глоссарии](glossary.md).

| Термин | Простыми словами |
|--------|------------------|
| **SDR** | Радиоприёмник, бо́льшую часть обработки в котором выполняет программа |
| **RTL-SDR** | Недорогой USB-приёмник для начального уровня |
| **HI** | Нейтральный водород; учебная цель на 1420 МГц / 21 см |
| **МШУ (LNA)** | Малошумящий усилитель, устанавливается у антенны |
| **RFI** | Искусственные радиопомехи (маршрутизатор, LED, зарядные устройства) |
| **Тюнер** | Микросхема выбора частоты внутри RTL-SDR (R820T2, R860, R828D) |
| **TCXO** | Термокомпенсированный генератор; частота приёмника стабильнее |
| **Bias-T** | Подача питания на МШУ по тому же коаксиалу, что и сигнал |

---

## Принцип: покупать поэтапно

Оборудование приобретается уровнями. Не следует собирать полноценную установку до первой успешной записи спектра.

```text
Уровень 0: проверка работоспособности SDR      (телескопической антенны достаточно)
Уровень 1: Солнце и более чистый приём
Уровень 2: линия водорода                       (нужны антенна под HI + МШУ)
Уровень 3: стабильность, карта, автоматизация
```

Финансовое правило:

> Сначала недорогой рабочий тракт, затем улучшение наиболее узкого места.
> Как правило, узкое место — антенна, МШУ или помехи, а не ноутбук.

Краткий выбор антенны по задаче:

| Задача | Что использовать |
|--------|-----------|
| Первый вечер, FM, проверка Linux/SDR | Телескопический диполь из комплекта |
| Линия водорода 1420 МГц | Яги / dual-dipole / небольшое зеркало + МШУ |
| Приём HI на телескопическую антенну | Не рекомендуется — работает неудовлетворительно |

Подробный разбор антенн — в справочнике [«Антенны, зеркала и тракт под HI»](reference/antennas.md).

## Уровень 0 — минимальный комплект

Достаточен для знакомства с темой за один вечер.

| Компонент | Рекомендация | Назначение |
|-----------|--------------|--------|
| SDR | **RTL-SDR Blog V3 или V4** (тюнер R820T2/R860/R828D) | Приёмник |
| Антенна | Телескопический диполь из комплекта | Проверка тракта |
| ПК | Небольшой ноутбук с **Linux** | ПО, запись, полевые условия |
| USB-кабель | Короткий качественный USB 2.0 | Питание и данные |
| Переходники | Запас SMA | Меньше сложностей в дальнейшем |

**Ориентировочный бюджет:** $30–70 (модуль + качественный USB; ноутбук учитывается отдельно).

Цель уровня: FM, ADS-B, спектрограмма, освоение интерфейса. Приём HI на этом уровне не выполняется.

### SDR: что брать

**Подходящий старт:** RTL-SDR Blog **V3** или **V4**. В описании желательны:

- тюнер из семейства **R820T2 / R860 / R828D** (не безымянный «RTL2832» без указания тюнера);
- разъём **SMA** (удобнее MCX при частых переподключениях);
- **TCXO** — меньший уход частоты;
- встроенный **bias-t** — удобно для последующего питания МШУ по коаксиалу.

Внутри недорогого RTL-SDR обычно две микросхемы:

```text
антенна → ТЮНЕР (выбор частоты) → RTL2832U (оцифровка + USB) → компьютер
```

Требование «нужен R820T2» относится именно к **тюнеру**. Подходящие варианты:

| Тюнер | Комментарий |
|-----|-------------|
| **R820T2** | Классика RTL-SDR; подходит для HI ~1420 МГц |
| **R860** | Тот же класс (часто в новых партиях V3); рабочий аналог |
| **R828D** | Установлен в Blog V4; для HI также подходит |
| R820T (без «T2») | Немного хуже; при выборе рядом предпочесть T2/R860/R828D |

Различие V3 и V4 — по сути в приёме КВ и фильтрации входа; **для линии водорода подходят обе версии**:

| | Blog V3 | Blog V4 |
|--|---------|---------|
| Тюнер | R820T2 / R860 | R828D |
| HI 1420 МГц | Подходит | Подходит |
| КВ (HF) | Direct sampling (менее устойчиво) | Upconverter (обычно чище) |
| Город (сильные станции) | Проще | Triplexer + notch — устойчивее |
| Драйверы Linux | Поддерживаются давно | Нужна поддержка V4 в драйвере |

**Чего избегать на старте:** безымянных модулей без TCXO и отзывов; модулей только с MCX при частой смене антенн; сразу дорогих Airspy/SDRPlay/HackRF «на перспективу» — **первая регистрация HI выполняется на RTL-SDR**.

Как отличить некачественный лот на маркетплейсе — в справочнике [«Закупки в РФ»](reference/buying-russia.md).

### Аналоги и апгрейды приёмника

RTL-SDR — не единственный вариант. Требование к любому аналогу для этой задачи: **приём на ~1420 МГц** и **вывод IQ в компьютер** (работа с GQRX/SDR++/GNU Radio). По этому признаку:

| Приёмник | Диапазон | АЦП | Bias-T | Роль |
|----------|----------|-----|--------|------|
| RTL-SDR Blog V4 / Nooelec NESDR SMArTee | до ~1,7 ГГц | 8-бит | есть | Бюджетный старт; достаточно для первой HI |
| **Airspy Mini / R2** | 24–1800 МГц | 12-бит | есть | Апгрейд: выше чувствительность, чище сигнал в городе |
| **SDRplay RSP1B / RSPdx** | 1 кГц–2 ГГц | 14-бит | есть | Апгрейд: широкий динамический диапазон против сильных помех |
| HackRF One | 1 МГц–6 ГГц | 8-бит | есть | Приём 1420 возможен, но 8-бит и избыточен для HI |
| ADALM-Pluto | 325 МГц–3,8 ГГц | 12-бит | нет | Приём 1420 возможен; сложнее, МШУ питать отдельно |

**Частая ошибка:** **Airspy HF+ / HF+ Discovery** и российские КВ/УКВ-приёмники (Expert Electronics ColibriNANO, SunSDR2) — только короткие/метровые волны и **до 1420 МГц не добивают**, поэтому для линии водорода не годятся, несмотря на высокое качество. Для L-диапазона нужен Airspy **Mini/R2**, а не HF+.

Вывод: для первой HI достаточно приёмника класса RTL-SDR; лучший по соотношению цена/результат апгрейд — **Airspy Mini** (12-бит) или **SDRplay RSP1B** (14-бит).

### Телескопическая антенна

Комплектный телескопический диполь пригоден для **88–108 МГц (FM)** и освоения интерфейса, но малопригоден на 1420 МГц. Порядок использования:

1. Раздвинуть плечи под нужную длину для FM (порядок десятков см на плечо; для проверки точность некритична).
2. Установить вертикально или под углом у окна.
3. На время проверки убрать поблизости маршрутизатор и зарядные устройства.

Профиля Млечного Пути от такой антенны ожидать не следует.

### Ноутбук и USB-кабель

Минимальные требования (подробнее — в [04. Программное обеспечение](04-software.md)):

- порт USB 2.0 напрямую, без неисправного хаба;
- не менее 4 ГБ RAM, комфортнее 8 ГБ; SSD предпочтительнее HDD;
- исправная батарея (для проверок шума БП).

USB-кабель — короткий и качественный: недорогой длинный даёт пропуски отсчётов и посторонний шум.

## Уровень 1 — Солнце и более чистый приём

Актуален после того, как уровень 0 работает.

| Компонент | Назначение |
|-----------|--------|
| Антенна выше / дальше от маршрутизатора | Меньше бытовых помех |
| Наблюдение от батареи ноутбука | Исключение шума сетевого БП |
| Аккуратная укладка кабелей | Меньше наводок |
| Заметки сессии | Возможность понять, что помогло |

Солнце нередко заметно даже на скромной антенне как подъём общего уровня при сравнении «на Солнце / в сторону от него».

---

## Уровень 2 — линия водорода (что понадобится)

Переход к полноценной домашней радиоастрономии. Основное — направленная антенна под HI и МШУ у неё.

| Компонент | Рекомендация |
|-----------|--------------|
| SDR | Тот же RTL-SDR Blog V3/V4 (уже есть) |
| Антенна HI | Яги / dual-dipole / небольшое зеркало под 21 см |
| МШУ | Под 1420 МГц, низкий NF, **у антенны** |
| Фильтр | Band-pass / SAW около 1420 (особенно в городе) |
| Кабель антенна→МШУ | Максимально короткий |
| Питание МШУ | Bias-T или отдельное |
| Переходники SMA | 2–4 шт. |

**Ориентировочный бюджет:** $80–200 к уже купленному SDR (самодельная Яги существенно снижает стоимость).

Ключевой принцип уровня 2:

```text
Антенна ──очень короткий кабель──► МШУ (+фильтр) ──кабель──► SDR ──USB──► ноутбук
```

> МШУ рядом с антенной важнее, чем «идеальный» длинный кабель от голой антенны до помещения.

Полный разбор — выбор антенны и зеркала, МШУ и фильтров, кабелей, типовых связок и апгрейдов уровня 3 — в справочнике [«Антенны, зеркала и тракт под HI»](reference/antennas.md).

## Чего не покупать на старте

- Крупное зеркало без места, крепежа и понимания облучателя.
- «Мощный широкополосный усилитель» вместо МШУ под HI.
- Десяток антенн до первой записи.
- Метры самого тонкого кабеля вместо короткого патча + МШУ.
- HackRF в качестве первого приёмника HI (избыточно).
- Любые TX-эксперименты «усилить космос передатчиком»: это не работает и может быть противоправно. См. [09](09-safety-and-legal.md).

## Чек-лист перед заказом

- [ ] Определён уровень закупки (0 / 2 / 3)
- [ ] Есть место под антенну (окно / балкон / двор)
- [ ] Для HI предусмотрен МШУ у антенны, а не «позднее»
- [ ] Кабель антенна→МШУ будет коротким
- [ ] Есть план питания МШУ (bias-t / отдельное)
- [ ] Приобретён запас переходников SMA
- [ ] Ноутбук с Linux готов или запланирован

## Чек-лист после распаковки

- [ ] `rtl_test` на Linux видит модуль
- [ ] Телескопическая антенна показывает FM
- [ ] Bias-t отключён, пока МШУ не подключён корректно
- [ ] Кабели и блок питания подписаны
- [ ] Создан каталог `~/radio-data/` для сессий

---

## Частые ошибки начинающего

1. Попытка приёма HI на комплектную телескопическую антенну.
2. Установка МШУ в помещении после 10 м тонкого кабеля.
3. Максимальное усиление и восприятие перегрузки как «богатого сигнала».
4. Игнорирование LED/зарядных устройств/PLC как источника «линии».
5. Приобретение зеркала без учёта облучателя/фокуса/МШУ.
6. Сравнение спектров при разных gain/PPM.
7. Отсутствие записи az/el и условий сессии.

---

## Что приобрести в первую очередь (кратко)

Если оборудования пока нет:

1. **RTL-SDR класса V3/V4** (R820T2/R860/R828D + SMA + TCXO + желательно bias-t)
2. Ноутбук под Linux (или установка Linux на имеющийся)
3. Комплектная телескопическая антенна — для проверки
4. Затем, на уровне 2: **самодельная Яги 21 см** + МШУ/фильтр под 1420

Крупное зеркало 2 м+ «на перспективу» откладывается. На балконе чаще предпочтительнее Яги.
