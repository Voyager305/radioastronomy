## Простой анализ в Python

Ниже — учебный каркас. Подправь чтение CSV под свой формат колонок.

```python
import numpy as np
import matplotlib.pyplot as plt

def load_spectrum(path):
    # ожидаем: frequency_mhz, power
    data = np.loadtxt(path, delimiter=",", skiprows=1)
    freq = data[:, 0]
    power = data[:, 1]
    return freq, power

def smooth(y, win=21):
    win = max(3, win | 1)  # нечётный
    kernel = np.ones(win) / win
    return np.convolve(y, kernel, mode="same")

freq_on, p_on = load_spectrum("on_milkyway.csv")
freq_off, p_off = load_spectrum("off_pole.csv")

# если сетки чуть разъехались — интерполируй off на freq_on
p_off_i = np.interp(freq_on, freq_off, p_off)

ratio = p_on / p_off_i
diff = p_on - p_off_i

plt.figure()
plt.plot(freq_on, smooth(ratio), label="on/off")
plt.axvline(1420.405751, linestyle="--", label="rest HI")
plt.xlabel("Frequency, MHz")
plt.ylabel("Relative power")
plt.legend()
plt.grid(True)
plt.show()
```

Для первой работы часто удобнее **отношение on/off** или аккуратная разность после нормализации.

## Baseline: убрать «чашу» и наклон

Даже без космоса спектр может быть кривым из‑за полосы приёмника и фильтров.

Простые приёмы:

1. Вычесть медианный уровень вне ожидаемой линии.
2. Подгнать полином низкой степени по крыльям спектра и вычесть.
3. Не вычитать так агрессивно, чтобы убить широкий реальный профиль.

Правило: если после «красивой» обработки линия существует только при одном выборе параметров — относись к ней с подозрением.

## Перевод в скорость

Используем ту же формулу, что в [физике](02-physics-basics.md):

```text
v ≈ c · (f₀ − f) / f₀
```

| Символ | Смысл | В коде ниже |
|--------|--------|-------------|
| v | лучевая скорость | возвращаемое значение, км/с |
| c | скорость света | `C = 299792.458` км/с |
| f₀ | покойная частота HI | `F0 = 1420.405751` МГц |
| f | частота бина спектра | `freq_mhz` |

```python
C = 299792.458  # км/с
F0 = 1420.405751  # МГц

def mhz_to_v_km_s(freq_mhz, f0=F0):
    return C * (f0 - freq_mhz) / f0
```

Построй график v vs мощность. Так проще сравнивать с учебными профилями Галактики.

На следующем уровне добавь поправки к LSR — но это уже после стабильного обнаружения.

## Усреднение и SNR

Если есть много коротких спектров:

```python
stack = np.vstack(power_list)  # shape: [n_spec, n_freq]
mean_spec = stack.mean(axis=0)
```

Помни: SNR ∝ √τ. Смотри, как шум падает с ростом числа спектров N (это тоже рост эффективного τ). Если иголка RFI не падает, а линия «растёт» относительно шума в нужных направлениях — хороший знак.

## Быстрый чеклист интерпретации

- [ ] Лишний сигнал есть в on, слабее в off
- [ ] Ширина правдоподобна (не 1 бин)
- [ ] Не совпадает 1-в-1 с домашней LED-иглой
- [ ] Повтор во вторую сессию похож
- [ ] При повороте антенны поведение разумное

Если три пункта «нет» — это ещё не открытие, а отладка установки.

## Мини-отчёт первой линии

Напиши себе одну страницу:

1. Схема антенны и LNA.
2. Два направления (on/off).
3. График до и после усреднения.
4. Почему это похоже на HI (или почему нет).
5. Что улучшить в следующей сессии.

Этот отчёт — главный артефакт новичка.

## Следующий уровень анализа

Когда базовый профиль стабилен:

- карта по азимуту (каждый N градусов — спектр);
- тепловая карта: азимут × скорость;
- сравнение с открытыми HI-обзорами;
- учёт gain-драйфта во времени.
