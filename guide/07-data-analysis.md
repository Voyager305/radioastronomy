Цель — получить из сырого спектра обоснованный вывод: «профиль HI присутствует» или «пока отсутствует».

## Минимальный конвейер обработки

```text
Сырые спектры (on / off)
        ↓
Выравнивание частотной оси (PPM, центр)
        ↓
Усреднение по времени
        ↓
Нормировка / вычитание baseline
        ↓
Сравнение on и off
        ↓
(опционально) пересчёт МГц → км/с
```

## Простой анализ на Python

Ниже — учебный каркас. Чтение CSV подстраивается под фактический формат колонок.

```python
import numpy as np
import matplotlib.pyplot as plt

def load_spectrum(path):
    # ожидается: frequency_mhz, power
    data = np.loadtxt(path, delimiter=",", skiprows=1)
    freq = data[:, 0]
    power = data[:, 1]
    return freq, power

def smooth(y, win=21):
    win = max(3, win | 1)  # нечётный
    kernel = np.ones(win) / win
    return np.convolve(y, kernel, mode="same")

freq_on, p_on = load_spectrum("on_milkyway.csv")
freq_off, p_off = load_spectrum("off_pole.csv")

# если сетки частот немного различаются — интерполяция off на freq_on
p_off_i = np.interp(freq_on, freq_off, p_off)

ratio = p_on / p_off_i
diff = p_on - p_off_i

plt.figure()
plt.plot(freq_on, smooth(ratio), label="on/off")
plt.axvline(1420.405751, linestyle="--", label="rest HI")
plt.xlabel("Frequency, MHz")
plt.ylabel("Relative power")
plt.legend()
plt.grid(True)
plt.show()
```

![Ожидаемый результат: профиль HI на ON и его отсутствие на OFF](images/hi-profile.png)

*Так выглядит цель анализа: избыток на ON относительно OFF в окрестности 1420.4 МГц (синтетические данные).*

Для первой обработки удобнее **отношение on/off** либо аккуратная разность после нормировки.

## Baseline: устранение «чаши» и наклона

Даже без космического сигнала спектр может быть искривлён из‑за полосы приёмника и фильтров.

Простые приёмы:

1. Вычесть медианный уровень вне ожидаемой линии.
2. Аппроксимировать крылья спектра полиномом низкой степени и вычесть его.
3. Не применять вычитание настолько агрессивно, чтобы подавить широкий реальный профиль.

Правило: если после обработки линия существует только при одном конкретном наборе параметров, к ней следует относиться с осторожностью.

## Пересчёт в скорость

Используется формула из [основ физики](02-physics-basics.md):

```text
v ≈ c · (f₀ − f) / f₀
```

| Символ | Смысл | В коде ниже |
|--------|--------|-------------|
| v | лучевая скорость | возвращаемое значение, км/с |
| c | скорость света | `C = 299792.458` км/с |
| f₀ | покоящаяся частота HI | `F0 = 1420.405751` МГц |
| f | частота бина спектра | `freq_mhz` |

```python
C = 299792.458  # км/с
F0 = 1420.405751  # МГц

def mhz_to_v_km_s(freq_mhz, f0=F0):
    return C * (f0 - freq_mhz) / f0
```

График «v — мощность» удобнее для сравнения с учебными профилями Галактики.

На следующем уровне добавляются поправки к LSR, но уже после устойчивого обнаружения.

## Усреднение и SNR

При наличии множества коротких спектров:

```python
stack = np.vstack(power_list)  # форма: [n_spec, n_freq]
mean_spec = stack.mean(axis=0)
```

Следует помнить: SNR ∝ √τ. Отслеживается, как шум убывает с ростом числа спектров N (это эквивалентно росту эффективного τ). Если пик RFI не убывает, а линия «растёт» относительно шума в нужных направлениях — это благоприятный признак.

## Краткий чек-лист интерпретации

- [ ] Дополнительный сигнал присутствует в on, слабее в off
- [ ] Ширина правдоподобна (не 1 бин)
- [ ] Нет точного совпадения с бытовым пиком LED
- [ ] Повтор во второй сессии похож
- [ ] При повороте антенны поведение согласуется с ожидаемым

Если три пункта отрицательны, это ещё не обнаружение, а отладка установки.

## Мини-отчёт по первой линии

Одностраничный отчёт для себя:

1. Схема антенны и МШУ.
2. Два направления (on/off).
3. График до и после усреднения.
4. Обоснование сходства с HI (или его отсутствия).
5. Что улучшить в следующей сессии.

Такой отчёт — основной результат работы начинающего.

## Следующий уровень анализа

После стабилизации базового профиля от одномерного спектра переходят к **радиоизображениям**:

- карта по азимуту (спектр через каждые N градусов);
- тепловая карта: азимут × скорость;
- сравнение с открытыми обзорами HI;
- учёт дрейфа усиления во времени.

Как из серии спектров собрать двумерную карту, что такое куб данных, интерферометрия и синтез апертуры — в справочнике [«Радиоизображения: получение и обработка»](reference/radio-imaging.md).
