## Астрономия и космос

**Астрономия** — наука о том, что есть на небе и как это выглядит/движется.

**Астрофизика** — объяснение неба через физику: из чего состоит, почему светит, какие скорости и температуры.

**Галактика** — огромный «остров» из звёзд, газа, пыли и тёмной материи. Мы живём внутри одной из них.

**Млечный Путь** — наша Галактика. Ночная светлая полоса на небе — взгляд вдоль её диска.

**Галактический диск** — «блин», в котором сосредоточены большинство звёзд и газа Галактики.

**Галактическая плоскость** — средняя плоскость диска. Вдоль неё HI-сигнал обычно сильнее.

**Галактический полюс** — направление «перпендикулярно диску»; удобно как off-source для сравнения.

**Межзвёздная среда (МЗС / ISM)** — вещество между звёздами: газ, пыль, космические лучи, поля.

**Облако HI** — область нейтрального водорода в МЗС; не водяное облако.

**Звезда** — огромный шар плазмы, светящий за счёт ядерных реакций (Солнце — ближайшая).

**Солнце** — наша звезда; сильный и удобный радиоисточник для первых опытов.

**Планета** — тело на орбите вокруг звезды; для домашнего HI обычно не цель.

**Туманность** — видимое облако газа/пыли; в радио часто важнее не «картинка», а спектральная линия.

**Пульсар** — быстро вращающаяся нейтронная звезда с ритмичными радиоимпульсами; новичку сложно.

**Радиоисточник** — любой объект, заметный в радиоволнах (Солнце, Галактика, далёкие галактики…).

**Континуум** — широкополосное излучение без узкой линии (как «общий шум» Солнца).

**Спектральная линия** — узкая (или относительно узкая) особенность на конкретной частоте; HI — пример.

**Красное смещение** — сдвиг линии в сторону меньших частот / больших длин волн при удалении источника.

**Голубое смещение** — сдвиг в сторону больших частот при приближении источника.

**Лучевая скорость v** — скорость объекта к тебе или от тебя вдоль луча зрения.

**LSR (Local Standard of Rest)** — стандартная система отсчёта скоростей в галактической астрономии (уточнение после первых наблюдений).

**Координаты на небе** — способ сказать «куда смотреть»: az/el, RA/Dec и т.п.

**Азимут (azimuth, az)** — направление по горизонту (примерно как компас), обычно в градусах.

**Высота / элевация (elevation, el)** — угол вверх от горизонта: 0° — горизонт, 90° — зенит.

**Зенит** — точка прямо над головой.

**Горизонт** — линия, где небо «встречается» с землёй с точки зрения наблюдателя.

**Транзит** — прохождение источника через выбранное направление/меридиан; удобно для длинных записей.

**UTC** — всемирное время; им удобно метить научные записи.

## Физика волн и излучения

**Электромагнитное излучение** — общее имя для радио, микроволн, ИК, видимого света, УФ, рентгена, гамма.

**Радиоволна** — электромагнитная волна с большой длиной волны (от миллиметров до километров и больше).

**Видимый свет** — узкая полоска электромагнитного спектра, которую видит глаз.

**Фотон** — «порция» электромагнитного излучения; для старта можно думать как о частице света/радио.

**Волна** — распространяющееся колебание; у ЭМ-волны колеблются электрическое и магнитное поля.

**Длина волны λ** — расстояние между соседними гребнями волны. Для HI: λ ≈ 21.1 см.

**Частота f (или ν)** — число колебаний в секунду. Связь: λ = c / f.

**Период T** — время одного колебания: T = 1 / f.

**Скорость света c** — скорость ЭМ-волн в вакууме: ≈ 3.00·10⁸ м/с.

**Герц (Гц)** — единица частоты: 1 колебание/с.  
кГц = 10³ Гц, МГц = 10⁶ Гц, ГГц = 10⁹ Гц.

**Амплитуда** — «сила» колебания; на практике связана с мощностью сигнала.

**Мощность** — сколько энергии приходит в единицу времени; на спектре часто рисуют относительную мощность.

**Интенсивность** — насколько «ярко» излучение в данном направлении/частоте (упрощённо).

**Поляризация** — ориентация колебаний поля волны; на старте можно игнорировать.

**Интерференция** — сложение волн; может усиливать или ослаблять сигнал (важно позже, в интерферометрии).

**Дифракция** — огибание волнами препятствий; связано с шириной луча антенны.

**Эффект Доплера** — движение источника меняет наблюдаемую частоту. Рабочая формула: v ≈ c·(f₀ − f)/f₀.

**Покойная частота f₀** — частота линии в системе покоя источника/лаборатории. Для HI ≈ 1420.405751 МГц.

**Сдвиг частоты Δf** — разница между f₀ и наблюдаемой f.

**Спектр** — зависимость силы сигнала от частоты (график).

**Водопад (waterfall / spectrogram)** — спектр во времени: по одной оси частота, по другой время, яркость = сила.

**Профиль линии** — форма спектральной линии (холмик, несколько пиков) после усреднения.

**Baseline** — плавная «подложка» спектра без линии; её вычитают, чтобы линия читалась лучше.

**Полоса / bandwidth Δν** — ширина частотного окна, которое ты смотришь сразу.

**Центральная частота f_c** — середина окна настройки SDR.

**Разрешение по частоте** — насколько мелкие детали спектра ты различаешь (зависит от FFT/полосы/усреднения).

## Водород и линия 21 см

**Элемент** — вид атомов с данным числом протонов; водород — самый простой.

**Атом** — мельчайший нейтральный кирпичик вещества.

**Протон** — положительная частица в ядре; у водорода ядро часто = один протон.

**Электрон** — лёгкая отрицательная частица вокруг ядра.

**Нейтральный атом** — суммарный заряд ноль (электроны компенсируют ядро).

**Ион** — атом/молекула с зарядом (потерял или приобрёл электрон).

**HI (аш-один)** — нейтральный атомарный водород. Главная учебная цель новичка.

**HII (аш-два)** — ионизованный водород (часто горячие области около ярких звёзд); это уже другая тема.

**Молекулярный водород H₂** — два атома вместе; в радио у любителя обычно не первый шаг.

**Линия 21 см** — радиолиния HI с λ ≈ 21 см / f₀ ≈ 1420.4 МГц.

**Спин** — квантовое свойство частиц; переход спинов протона и электрона даёт линию 21 см (детали — позже).

**Эмиссионная линия** — линия, где источник излучает (добавляет сигнал).

**Абсорбционная линия** — линия, где газ поглощает фон; новичку сначала важнее эмиссия HI.

## Шум, сигнал, чувствительность

**Сигнал** — то, что ты хочешь измерить (HI, Солнце…).

**Шум** — случайная/мешающая составляющая, которая маскирует сигнал.

**RFI (Radio Frequency Interference)** — искусственные радиопомехи: LED, зарядки, Wi‑Fi, БП…

**SNR (Signal-to-Noise Ratio)** — отношение сигнал/шум. Чем выше, тем увереннее обнаружение.

**Усреднение / интеграция** — накопление данных за время τ, чтобы поднять SNR. Часто SNR ∝ √τ.

**Время накопления τ** — сколько секунд/минут ты усредняешь спектр.

**Чувствительность** — способность увидеть слабый сигнал; растёт с площадью антенны, низким шумом и временем τ.

**Шумовая температура** — способ описать шум системы в «кельвинах»; термин встретишь в учебниках уровнем выше.

**Перегрузка (overload / saturation)** — слишком сильный сигнал/помеха «забивает» приёмник; спектр искажается.

**Динамический диапазон** — способность одновременно видеть сильное и слабое; у дешёвого SDR ограничен.

**Калибровка** — процедура, которая делает измерения сравнимыми (частота, усиление, on/off…).

**On-source** — наблюдение «на цель» (например, на Млечный Путь).

**Off-source** — наблюдение «мимо цели» для сравнения и вычитания фона/аппаратной кривой.

**Артефакт** — ложная особенность на спектре (помеха, баг ПО, перегруз), не космос.

## Антенны и СВЧ-тракт

**Антенна** — металлическая конструкция, которая принимает (или излучает) радиоволны.

**Диаграмма направленности** — карта, куда антенна хорошо «слышит», а куда плохо.

**Главный лепесток / луч** — основное направление максимальной чувствительности.

**Ширина луча θ** — угловая ширина главного лепестка. Оценка для тарелки: θ ≈ λ / D (в радианах).

**Апертура / диаметр D** — характерный размер собирающей поверхности (у тарелки — диаметр).

**Усиление антенны (antenna gain)** — насколько антенна сильнее собирает с нужного направления по сравнению с идеализированным изотропным случаем.

**Диполь** — простая антенна из двух плеч; широко ловит, мало «отсекает» помехи.

**Яги (Yagi)** — направленная антенна из нескольких элементов; популярна для HI.

**Параболическая тарелка** — отражает волны в фокус, где стоит облучатель; даёт более узкий луч.

**Облучатель (feed)** — антенный элемент в фокусе тарелки.

**Helical (спираль)** — спиральная антенна; иногда используют на L-диапазоне.

**КСВ / VSWR** — показатель согласования антенны с кабелем; плохой КСВ = потери и капризы (углублять позже).

**Коаксиальный кабель (коаксиал)** — кабель с центральной жилой и экраном; несёт сигнал от антенны/LNA к SDR.

**Разъём SMA / N-type** — типы СВЧ-разъёмов; у RTL-SDR часто SMA.

**Потери в кабеле** — ослабление сигнала по дороге; длинный тонкий кабель до LNA вреден.

**LNA (Low Noise Amplifier)** — малошумящий усилитель; ставят ближе к антенне.

**Noise figure (NF)** — характеристика шумности усилителя; меньше — обычно лучше.

**Фильтр (band-pass)** — пропускает нужный диапазон частот и режет чужой мусор.

**SAW-фильтр** — компактный фильтр на поверхностных акустических волнах; часто рядом с HI-LNA.

**Bias-T** — подача питания на LNA через тот же коаксиал.

**Заглушка / dummy load 50 Ω** — согласованная нагрузка вместо антенны для тестов.

**Экранирование** — защита от наводок металлом/корпусом.

**Заземление** — соединение с землёй для безопасности и иногда для снижения наводок.

## SDR, компьютеры и ПО

**SDR (Software Defined Radio)** — радио, где основную обработку делает программа.

**RTL-SDR** — дешёвый USB-приёмник на RTL2832U; стартовый инструмент гайда.

**Tuner / R820T2** — микросхема настройки частоты в многих RTL-SDR.

**Sample rate (f_s)** — сколько отсчётов сигнала в секунду пишет SDR; связано с полосой.

**IQ-данные** — сырой комплексный поток отсчётов; из него потом делают спектр.

**FFT** — алгоритм быстрого преобразования Фурье: из сигнала во времени делает спектр.

**Бин спектра** — один столбик/точка частотной сетки после FFT.

**Gain (RF/IF gain)** — усиление в приёмнике. Мало — глухо; много — перегруз и мусор.

**AGC** — авторегулировка усиления; для измерений часто лучше ручной gain.

**PPM** — поправка частоты в миллионных долях; калибрует уход генератора RTL-SDR.

**TCXO** — термокомпенсированный генератор; частота стабильнее, чем у дешёвых стиков без него.

**USB** — шина, по которой стик получает питание и отдаёт данные.

**udev** — в Linux система правил для устройств; влияет на права доступа к RTL-SDR.

**GQRX / SDR++ / CubicSDR** — программы для живого спектра и водопада.

**GNU Radio** — конструктор радиообработки из блоков; удобен для автоусреднения.

**Python** — язык для анализа спектров (numpy, matplotlib…).

**CSV** — текстовая таблица; удобно сохранять спектры новичку.

**Метаданные** — описание сессии: время, f_c, gain, PPM, az/el, батарея/сеть…

**Драйвер** — ПО, которое позволяет ОС видеть устройство (на Linux обычно проще через пакеты `rtl-sdr`).

## Наблюдательная практика

**Сессия** — один законченный набор наблюдений с заметками и файлами.

**Протокол наблюдения** — заранее продуманный порядок действий (прогрев, on/off, повтор).

**Прогрев** — время после включения, пока частота/температура железа стабилизируются.

**Скан по азимуту** — серия спектров в разных направлениях по горизонту.

**Карта** — собранная картина параметра по небу (например, яркость HI или скорость).

**Воспроизводимость** — получается ли тот же результат в другой день при тех же условиях.

**Sanity-check** — быстрая проверка «я не измеряю розетку?»: поворот антенны, on/off, выключение LED.

**Полевой выезд** — наблюдения вне города, где меньше RFI.

**Радиотишина** — условия с малым уровнем искусственных помех (относительно).

## Единицы и обозначения (шпаргалка)

| Символ | Смысл |
|--------|--------|
| λ | длина волны |
| f, ν | частота |
| T | период |
| c | скорость света |
| f₀ | покойная частота линии |
| f_c | центральная частота SDR |
| f_s | sample rate |
| Δf | сдвиг частоты |
| Δν | полоса |
| v | лучевая скорость |
| τ | время усреднения |
| SNR | сигнал/шум |
| D | размер антенны |
| θ | ширина луча |
| az, el | азимут и высота |

Частые формулы:

```text
λ = c / f
T = 1 / f
Δf / f₀ ≈ v / c
v ≈ c · (f₀ − f) / f₀
SNR ∝ √(Δν · τ)
θ ≈ λ / D
```
