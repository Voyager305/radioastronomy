## Астрономия и космос

**Астрономия** — наука о том, что находится на небе и как это выглядит и движется.

**Астрофизика** — объяснение небесных объектов через физику: состав, механизм свечения, скорости и температуры.

**Галактика** — крупная система из звёзд, газа, пыли и тёмной материи. Солнечная система находится внутри одной из них.

**Млечный Путь** — Галактика, в которой находится Солнечная система. Светлая полоса на ночном небе — взгляд вдоль плоскости её диска.

**Галактический диск** — уплощённая область, в которой сосредоточена бо́льшая часть звёзд и газа Галактики.

**Галактическая плоскость** — средняя плоскость диска. Вдоль неё сигнал HI обычно сильнее.

**Галактический полюс** — направление, перпендикулярное диску; удобно как off-source для сравнения.

**Межзвёздная среда (МЗС / ISM)** — вещество между звёздами: газ, пыль, космические лучи, поля.

**Облако HI** — область нейтрального водорода в МЗС; не водяное облако.

**Звезда** — массивный шар плазмы, излучающий за счёт ядерных реакций (Солнце — ближайшая).

**Солнце** — ближайшая звезда; сильный и удобный радиоисточник для первых наблюдений.

**Планета** — тело на орбите вокруг звезды; для домашнего приёма HI обычно не является целью.

**Туманность** — наблюдаемое облако газа/пыли; в радиодиапазоне часто важнее спектральная линия, чем изображение.

**Пульсар** — быстро вращающаяся нейтронная звезда с периодическими радиоимпульсами; для начинающего сложна.

**Радиоисточник** — любой объект, заметный в радиоволнах (Солнце, Галактика, далёкие галактики).

**Континуум** — широкополосное излучение без узкой линии (например, «общий шум» Солнца).

**Спектральная линия** — узкая особенность на определённой частоте; линия HI — пример.

**Красное смещение** — сдвиг линии в сторону меньших частот / больших длин волн при удалении источника.

**Голубое смещение** — сдвиг в сторону больших частот при приближении источника.

**Лучевая скорость v** — скорость объекта вдоль луча зрения (к наблюдателю или от него).

**LSR (Local Standard of Rest)** — стандартная система отсчёта скоростей в галактической астрономии (уточнение после первых наблюдений).

**Координаты на небе** — способ задания направления наблюдения: az/el, RA/Dec и др.

**Азимут (azimuth, az)** — направление по горизонту (аналогично компасу), обычно в градусах.

**Высота / элевация (elevation, el)** — угол над горизонтом: 0° — горизонт, 90° — зенит.

**Зенит** — точка прямо над наблюдателем.

**Горизонт** — линия видимой границы неба и земли для наблюдателя.

**Транзит** — прохождение источника через выбранное направление/меридиан; удобно для длительных записей.

**UTC** — всемирное координированное время; используется для меток научных записей.

## Физика волн и излучения

**Электромагнитное излучение** — общее название для радио, микроволн, ИК, видимого света, УФ, рентгеновского и гамма-излучения.

**Радиоволна** — электромагнитная волна большой длины (от миллиметров до километров и более).

**Видимый свет** — узкая полоса электромагнитного спектра, воспринимаемая глазом.

**Фотон** — квант электромагнитного излучения; для начального уровня допустимо представление о частице света/радио.

**Волна** — распространяющееся колебание; у ЭМ-волны колеблются электрическое и магнитное поля.

**Длина волны λ** — расстояние между соседними гребнями волны. Для HI: λ ≈ 21.1 см.

**Частота f (или ν)** — число колебаний в секунду. Связь: λ = c / f.

**Период T** — время одного колебания: T = 1 / f.

**Скорость света c** — скорость ЭМ-волн в вакууме: ≈ 3.00·10⁸ м/с.

**Герц (Гц)** — единица частоты: 1 колебание в секунду.
кГц = 10³ Гц, МГц = 10⁶ Гц, ГГц = 10⁹ Гц.

**Амплитуда** — величина колебания; на практике связана с мощностью сигнала.

**Мощность** — энергия, приходящая в единицу времени; на спектре обычно отображается относительная мощность.

**Интенсивность** — мера «яркости» излучения в данном направлении/частоте (упрощённо).

**Поляризация** — ориентация колебаний поля волны; на начальном этапе можно не учитывать.

**Интерференция** — сложение волн; может усиливать или ослаблять сигнал (существенно в интерферометрии).

**Дифракция** — огибание волнами препятствий; связана с шириной луча антенны.

**Эффект Доплера** — изменение наблюдаемой частоты при движении источника. Рабочая формула: v ≈ c·(f₀ − f)/f₀.

**Покоящаяся частота f₀** — частота линии в системе покоя источника/лаборатории. Для HI ≈ 1420.405751 МГц.

**Сдвиг частоты Δf** — разность между f₀ и наблюдаемой f.

**Спектр** — зависимость уровня сигнала от частоты (график).

**Спектрограмма (водопад, spectrogram)** — спектр во времени: по одной оси частота, по другой время, яркость соответствует уровню.

**Профиль линии** — форма спектральной линии (пик, несколько пиков) после усреднения.

**Baseline** — плавная подложка спектра без линии; вычитается для лучшей читаемости линии.

**Полоса / bandwidth Δν** — ширина частотного окна, наблюдаемого одновременно.

**Центральная частота f_c** — середина окна настройки SDR.

**Разрешение по частоте** — минимальная различимая деталь спектра (зависит от FFT/полосы/усреднения).

## Водород и линия 21 см

**Элемент** — вид атомов с данным числом протонов; водород — простейший.

**Атом** — мельчайшая нейтральная структурная единица вещества.

**Протон** — положительно заряженная частица ядра; у водорода ядро часто состоит из одного протона.

**Электрон** — лёгкая отрицательно заряженная частица вокруг ядра.

**Нейтральный атом** — суммарный заряд равен нулю (электроны компенсируют заряд ядра).

**Ион** — атом/молекула с ненулевым зарядом (потеря или присоединение электрона).

**HI («аш-один»)** — нейтральный атомарный водород. Основная учебная цель начального уровня.

**HII («аш-два»)** — ионизованный водород (часто горячие области вблизи ярких звёзд); отдельная тема.

**Молекулярный водород H₂** — два связанных атома; в любительском радиоприёме обычно не первый этап.

**Линия 21 см** — радиолиния HI с λ ≈ 21 см / f₀ ≈ 1420.4 МГц.

**Спин** — квантовое свойство частиц; переход, связанный со спинами протона и электрона, даёт линию 21 см (детали — позднее).

**Эмиссионная линия** — линия, на которой источник излучает (добавляет сигнал).

**Абсорбционная линия** — линия, на которой газ поглощает фоновое излучение; для начального уровня важнее эмиссия HI.

## Шум, сигнал, чувствительность

**Сигнал** — измеряемая величина (HI, Солнце и т. п.).

**Шум** — случайная/мешающая составляющая, маскирующая сигнал.

**RFI (Radio Frequency Interference)** — искусственные радиопомехи: LED, зарядные устройства, Wi‑Fi, БП.

**SNR (Signal-to-Noise Ratio)** — отношение сигнал/шум. Чем выше, тем увереннее обнаружение.

**Усреднение / интеграция** — накопление данных за время τ для повышения SNR. Часто SNR ∝ √τ.

**Время накопления τ** — длительность усреднения спектра.

**Чувствительность** — способность регистрировать слабый сигнал; растёт с площадью антенны, снижением шума и временем τ.

**Шумовая температура** — способ описания шума системы в кельвинах; термин встречается в литературе более высокого уровня.

**Перегрузка (overload / saturation)** — слишком сильный сигнал/помеха насыщает приёмник; спектр искажается.

**Динамический диапазон** — способность одновременно наблюдать сильные и слабые сигналы; у недорогого SDR ограничен.

**Калибровка** — процедура приведения измерений к сравнимому виду (частота, усиление, on/off).

**On-source** — наблюдение «на цель» (например, на Млечный Путь).

**Off-source** — наблюдение «в сторону от цели» для сравнения и вычитания фона/аппаратной кривой.

**Артефакт** — ложная особенность спектра (помеха, ошибка ПО, перегрузка), а не космический сигнал.

## Антенны и СВЧ-тракт

**Антенна** — проводящая конструкция, принимающая (или излучающая) радиоволны.

**Диаграмма направленности** — распределение чувствительности антенны по направлениям.

**Главный лепесток / луч** — направление максимальной чувствительности.

**Ширина луча θ** — угловая ширина главного лепестка. Оценка для зеркала: θ ≈ λ / D (в радианах; HPBW ≈ 70°·λ/D).

**Апертура / диаметр D** — характерный размер собирающей поверхности (у зеркала — диаметр).

**Усиление антенны (antenna gain)** — во сколько раз антенна эффективнее собирает сигнал с нужного направления по сравнению с изотропным излучателем.

**Диполь** — простая антенна из двух плеч; широкая диаграмма, слабое подавление помех.

**Яги (Yagi)** — направленная антенна из нескольких элементов; распространена для HI.

**Параболическое зеркало** — отражает волны в фокус, где размещён облучатель; даёт более узкий луч.

**Облучатель (feed)** — антенный элемент в фокусе зеркала.

**Helical (спираль)** — спиральная антенна; иногда применяется на L-диапазоне.

**Dual-dipole** — конструкция из двух диполей.

**Mesh / grid** — сетчатое или решётчатое зеркало; легче сплошного, меньше ветровая нагрузка.

**Solid-зеркало** — сплошное металлическое зеркало.

**Prime-focus** — схема с облучателем на оси в центре зеркала.

**Offset-зеркало** — спутниковое зеркало со смещённым фокусом; облучатель сбоку, геометрия сложнее для начинающего.

**f/D** — отношение фокусного расстояния к диаметру зеркала.

**Фокус** — точка, в которую парабола собирает волны; здесь размещается облучатель.

**Ku-LNB** — штатная головка спутникового ТВ (Ku-диапазон); для HI подлежит демонтажу.

**Cantenna** — самодельный облучатель из отрезка трубы или банки.

**Patch-feed** — плоский облучатель.

**КСВ / VSWR** — показатель согласования антенны с кабелем; плохой КСВ означает потери и нестабильность (углублённо — позднее).

**Коаксиальный кабель (коаксиал)** — кабель с центральной жилой и экраном; передаёт сигнал от антенны/МШУ к SDR.

**Патч-кабель** — короткий соединительный коаксиал.

**RG316** — тонкий гибкий коаксиал; удобен для коротких патчей.

**LMR-240** — коаксиал с меньшими потерями для средних длин (и аналоги).

**Hardline** — толстый жёсткий коаксиал для стационарных установок.

**Разъём SMA** — наиболее распространённый малогабаритный СВЧ-разъём у RTL-SDR.

**MCX** — более мелкий разъём; менее надёжен при частых переподключениях.

**N-type** — более крупный разъём, часто на уличных антеннах.

**Male / Female** — штырь / гнездо у разъёма.

**50 Ω** — стандартное волновое сопротивление антенн/кабелей/нагрузок тракта.

**Потери в кабеле** — ослабление сигнала на пути; длинный тонкий кабель до МШУ нежелателен.

**МШУ (LNA, Low Noise Amplifier)** — малошумящий усилитель; устанавливается ближе к антенне.

**Noise figure (NF)** — характеристика собственного шума усилителя в дБ; меньше — обычно лучше.

**Фильтр (band-pass)** — пропускает нужный диапазон частот и подавляет остальное.

**SAW-фильтр** — компактный фильтр на поверхностных акустических волнах; часто в составе МШУ под HI.

**SAWBird H1** — распространённый модуль МШУ+фильтр под линию водорода ~1420 МГц.

**Bias-T** — подача питания на МШУ по тому же коаксиалу, что и сигнал.

**Заглушка / dummy load 50 Ω** — согласованная нагрузка вместо антенны для проверок.

**Drip loop** — петля кабеля для стока дождя: вода стекает вниз, а не в разъём.

**Экранирование** — защита от наводок с помощью металла/корпуса.

**Заземление** — соединение с землёй для безопасности и снижения наводок.

**БП** — блок питания.

**Импульсный БП** — импульсный источник питания; частый сильный бытовой источник RFI.

**PLC** — передача данных по электросети; частый источник помех.

**LTE** — стандарт сотовой связи; сильные передатчики поблизости могут перегружать SDR.

**HF / КВ** — короткие волны (примерно до 30 МГц).

**VHF** — метровый диапазон (включая FM).

**UHF** — дециметровый диапазон; сюда в широком смысле относят и 1420 МГц.

**L-диапазон** — около 1–2 ГГц; здесь находится линия HI.

**Out-of-band** — сигналы вне нужной полосы частот.

**TX / RX** — передача / приём. В данном руководстве используется только приём (RX).

**DVB-T** — цифровое эфирное ТВ; исторический предшественник многих RTL-модулей.

**Direct sampling** — режим приёма в обход тюнера (на V3 для HF); легко перегружается.

**Upconverter** — перенос сигнала вверх по частоте; в Blog V4 улучшает приём HF.

**Triplexer** — схема разделения одного входа на несколько диапазонных путей.

**Notch-фильтр** — узкий вырез по частоте против сильной помехи/станции.

## SDR, компьютеры и ПО

**SDR (Software Defined Radio)** — радиоприёмник, в котором основную обработку выполняет программа.

**RTL-SDR** — недорогой USB-приёмник на RTL2832U; стартовый инструмент руководства.

**Тюнер** — микросхема выбора рабочей частоты до оцифровки (R820T2, R860, R828D).

**R820T2** — классический тюнер RTL-SDR; эталон прежних руководств по HI.

**R860** — тюнер того же класса, что R820T2 (часто в Blog V3); рабочий аналог.

**R828D** — тюнер Blog V4; для HI подходит, на Linux требуется поддержка V4.

**R820T** — предшественник R820T2; для учёбы приемлем, но T2/R860/V4 лучше.

**Sample rate (f_s)** — число отсчётов сигнала в секунду; связано с полосой.

**IQ-данные** — сырой комплексный поток отсчётов; из него строится спектр.

**FFT** — быстрое преобразование Фурье: переход от сигнала во времени к спектру.

**Бин спектра** — одна точка частотной сетки после FFT.

**Gain (RF/IF gain)** — усиление в приёмнике. Недостаточное — низкая чувствительность; избыточное — перегрузка.

**AGC** — автоматическая регулировка усиления; для измерений часто предпочтителен ручной gain.

**PPM** — поправка частоты в миллионных долях; компенсирует уход генератора RTL-SDR.

**TCXO** — термокомпенсированный генератор; частота стабильнее, чем у недорогих модулей без него.

**USB** — шина, по которой модуль получает питание и передаёт данные.

**udev** — в Linux система правил для устройств; влияет на права доступа к RTL-SDR.

**GQRX / SDR++ / CubicSDR** — программы для отображения живого спектра и спектрограммы.

**GNU Radio** — конструктор радиообработки из блоков; удобен для автоматического усреднения.

**Python** — язык для анализа спектров (numpy, matplotlib).

**CSV** — текстовая таблица; удобный формат для сохранения спектров на начальном этапе.

**Метаданные** — описание сессии: время, f_c, gain, PPM, az/el, тип питания.

**Драйвер** — ПО, позволяющее ОС работать с устройством (на Linux обычно проще через пакеты `rtl-sdr`).

## Наблюдательная практика

**Сессия** — законченный набор наблюдений с заметками и файлами.

**Протокол наблюдения** — заранее продуманный порядок действий (прогрев, on/off, повтор).

**Прогрев** — время после включения, за которое стабилизируются частота и температура оборудования.

**Скан по азимуту** — серия спектров в разных направлениях по горизонту.

**Карта** — собранное распределение параметра по небу (например, яркость HI или скорость).

**Воспроизводимость** — получение того же результата в другой день при тех же условиях.

**Sanity-check** — быстрая проверка на посторонний источник (поворот антенны, on/off, отключение LED).

**Полевой выезд** — наблюдения вне города, где ниже уровень RFI.

**Радиотишина** — условия с относительно малым уровнем искусственных помех.

| T | период |
| c | скорость света |
| f₀ | покоящаяся частота линии |
| f_c | центральная частота SDR |
| f_s | sample rate |
| Δf | сдвиг частоты |
| Δν | полоса |
| v | лучевая скорость |
| τ | время усреднения |
| SNR | сигнал/шум |
| D | размер антенны |
| θ | ширина луча |
| az, el | азимут и высота |

Частые формулы:

```text
λ = c / f
T = 1 / f
Δf / f₀ ≈ v / c
v ≈ c · (f₀ − f) / f₀
SNR ∝ √(Δν · τ)
θ ≈ λ / D
```
