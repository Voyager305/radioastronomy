# Справочник: закупки в РФ

← [03. Оборудование](../03-equipment.md) · [Оглавление](../../README.md) · [Антенны и тракт](antennas.md)

---

Это **справочный** материал. Руководство называет зарубежные бренды (RTL-SDR Blog, Nooelec, SAWBird) как **ориентиры по классу оборудования**, а не как единственные источники поставки. В РФ часть позиций:

- присутствует на Ozon / Wildberries / Avito;
- продаётся под другим названием («SDR V4», «RTL2832», «LNA 1420»);
- отсутствует месяцами;
- представлена клонами разного качества.

Правило:

> Выбор осуществляется **по характеристикам**, а не по названию на упаковке.
> При отсутствии оригинала подойдёт качественный аналог того же класса либо самостоятельная сборка антенны.

---

## Где искать

| Площадка | Обычный ассортимент |
|----------|------------------|
| **Ozon / Wildberries** | RTL-SDR класса V3/V4, SMA-кабели, переходники, иногда МШУ |
| **Avito** | Б/у модули, ТВ-зеркала, штативы, мачты, иногда готовые Яги |
| **Радиолюбительские магазины и клубы** | Разъёмы, коаксиал, корпуса, иногда МШУ под L-диапазон |
| **AliExpress / параллельный ввоз** | Позиции, отсутствующие локально; дольше и с риском по качеству |
| **Самостоятельная сборка** | Яги/диполь 21 см — часто оптимальный вариант при отсутствии готового набора |

Поисковые запросы:

```text
SDR RTL2832 SMA TCXO
SDR приёмник V3 bias-t
SDR приёмник V4 R828D
LNA 1420 МГц
LNA hydrogen / SAW 1420
усилитель малошумящий 1.4 ГГц
кабель SMA папа мама
переходник SMA
антенна Яги 1296 / 1420 / 23 см / 21 см
сетчатая парабола 1.4 ГГц
тарелка offset б/у
```

Запросы «1296 МГц / 23 см» полезны, поскольку радиолюбители часто продают оборудование соседнего любительского диапазона; иногда конструкцию удаётся адаптировать под 1420, но **не всегда** — требуется внимательная проверка.

## Позиции, которые редко доступны сразу

| Зарубежный ориентир | Ситуация в РФ | Что делать |
|---------------------|-----------------|------------|
| RTL-SDR Blog V3/V4 оригинал | Бывает, но не всегда; много безымянных «V4» | Выбирать с R820T2/R860/R828D + TCXO + SMA + bias-t |
| Nooelec SAWBird H1 | Может отсутствовать | МШУ 1420 + отдельный SAW/band-pass либо модуль «HI/1420» |
| Nooelec mesh 1.4 GHz kit | Редко в готовом виде | Яги своими руками / б/у зеркало + собственный облучатель |
| SARA Scope-in-a-Box | Скорее концепция комплекта, чем товар | Сборка по связке из справочника [«Антенны»](antennas.md) |
| Discovery Dish feed | Возможен дорогой/долгий заказ | Самодельный облучатель / cantenna + МШУ либо ожидание поставки |

## Что относительно доступно локально

Обычно проще найти:

1. **RTL-SDR класса V3/V4** (нередко без слова Blog).
2. **SMA-кабели и переходники**.
3. **Б/у спутниковые зеркала** на Avito.
4. **Штативы и крепёж**.
5. Иногда **МШУ под 1–2 ГГц** (проверять NF и наличие фильтра).
6. Материалы для **Яги**: трубку, провод, текстолит, крепёж.

Сложнее найти:

- проверенный МШУ под HI с качественным SAW-фильтром;
- готовое корректное mesh-зеркало под 1420;
- готовый согласованный облучатель.

Поэтому для начинающего в РФ часто оптимален маршрут:

```text
подходящий RTL-SDR с Ozon/WB
  → Linux на ноутбуке
  → самодельная Яги 21 см
  → МШУ (+фильтр) под 1420 из доступных
  → последующее улучшение фильтра/зеркала
```

## Как отличить некачественную позицию на маркетплейсе

Перед заказом на Ozon/WB рекомендуется проверить:

- [ ] В характеристиках указан **тюнер** (R820T2 / R860 / R828D), а не только RTL2832
- [ ] Присутствует **TCXO** либо есть отзывы о стабильности частоты
- [ ] Разъём **SMA**
- [ ] Bias-T упомянут и желательно подтверждён отзывами/фото
- [ ] Цена не «втрое ниже рынка» без объяснения
- [ ] Описание не сводится только к «подключению к смартфону»
- [ ] Для МШУ явно указано **1420 МГц / 1.4 ГГц / hydrogen**, а не «0–6 ГГц мощный»

При выборе между двумя лотами предпочтителен тот, где больше реальных фотографий платы и содержательных отзывов с упоминанием SDR#, GQRX или `rtl_test`.

## Замены при отсутствии позиции

| Требуется | Если нет в РФ | Замена |
|-------|---------------|--------|
| Blog V4 | Отсутствует | Любой подходящий V3/V4-класс с R820T2/R860/R828D |
| SAWBird H1 | Отсутствует | МШУ ~1420 с низким NF + отдельный фильтр 1420 |
| Готовый mesh-набор | Отсутствует | Самодельная Яги или б/у зеркало + облучатель |
| Дорогой облучатель под HI | Отсутствует | Cantenna/patch по чертежу + МШУ рядом |
| Фирменный LMR-кабель | Отсутствует | Качественный 50 Ω коаксиал покороче + хорошие SMA |
| Готовый набор SARA | Отсутствует | Сборка связки A/B из справочника [«Антенны»](antennas.md) |

## Оценка стоимости в рублях

В сметах руководства цены в долларах — порядок величины «мирового» уровня.
В РФ из‑за логистики и курса позиция может стоить заметно дороже. Для оценки полезно сравнивать:

- несколько продавцов на Ozon/WB;
- предложения б/у на Avito;
- вариант «дождаться оригинала» против «взять рабочий аналог сейчас».

Для старта предпочтителен **рабочий аналог сразу**, а не идеальный бренд спустя полгода.

## Б/у на Avito: что брать и с чем быть осторожным

**Можно брать (при известном состоянии):**

- спутниковое зеркало 0.8–1.2 м + отдельный план по облучателю;
- штатив, мачту, струбцины;
- кабели и переходники SMA;
- ноутбук под Linux.

**Требует осторожности:**

- безымянный SDR без возможности возврата/проверки;
- «МШУ для 4G» вместо HI;
- «готовая антенна для космоса» без указания размеров и резонансной частоты.

## Итог по рынку РФ

1. Не следует привязываться к одному бренду.
2. Ориентир — **класс оборудования**, а не название.
3. Антенну под HI в РФ чаще **изготавливают**, чем покупают готовым набором.
4. Модуль и мелочь SMA обычно доступны.
5. Наиболее дефицитны качественный **МШУ+фильтр 1420** и корректный **облучатель**.
